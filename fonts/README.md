# fonts/

このフォルダーに置いた `.ttf` / `.otf` / `.ttc` は、プレイヤーの「フォント設定」に一覧表示され、
Ruffle に読み込ませる置き換え用フォントとして使えます（ローカルサーバー経由で配信されます）。

- Windows のフォントは `C:\Windows\Fonts` からコピーできます（例: `msgothic.ttc`, `meiryo.ttc`, `YuGothR.ttc`）。
- ブラウザ画面にフォントファイルをドロップして追加することもできます（その場合はブラウザ内に保存されます）。
- 同梱の `BIZ-UDGothicR.ttc`（BIZ UDゴシック）は SIL Open Font License で配布されているフォントです。

Ruffle はフォントを **英語のファミリー名**（例: `MS Gothic`, `Meiryo`, `BIZ UDGothic`）で登録します。
「この SWF のフォント名の置き換え」で指定する名前にはこの英語名を使ってください（一覧に表示されます）。
